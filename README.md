# Proyecto de demostración: 5 Skills de Codex

**Guía principal para la grabación:** `GUION-GRABACION-CORREGIDO.md`.

Abrir la carpeta `codex-cinco-skills-demo` en Visual Studio Code, utilizar PowerShell integrado y ejecutar `npm test` para comprobar las 3 pruebas iniciales.

Dentro de `.agents/skills/` están las cinco Skills. El archivo `src/carrito.js` contiene la función `calcularTotal(productos, descuento = 0)`, que recibe un arreglo de objetos con `precio` y `cantidad`.

Sigue los pasos narrados de la guía principal, en el orden indicado.
