# Guía del proyecto

- El proyecto es una demostración educativa en JavaScript sin dependencias externas.
- Los tests se ejecutan con `npm test` (Node.js 18 o posterior).
- Conservar la API pública `calcularTotal(productos, descuento = 0)`.
- Antes de informar que un cambio está listo, ejecutar las pruebas y revisar `git diff`.
- No ejecutar `git add`, `git commit`, `git push` ni instalar dependencias sin autorización explícita.
